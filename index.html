Merist · Content Intelligence

Content operations for authorized connected accounts

Merist Content Intelligence helps operators research opportunities, prepare media, connect social accounts they own or are authorized to use, retrieve permitted analytics, and — where scopes allow — perform Draft Upload or Direct Post through official platform authorization.

Authorization model

  • Passwords Never collected — platform OAuth only
  • Accounts Only accounts the user explicitly authorizes
  • Analytics Where granted (profile, stats, video.list)
  • Draft Upload Under video.upload after confirm
  • Direct Post Under video.publish after confirm
  • Revocation Disconnect in Merist or revoke in TikTok settings

Platform limitations remain authoritative. Unaudited Direct Post remains subject to TikTok restrictions (for example SELF_ONLY / private). Unrestricted autonomous TikTok publishing remains disabled.

TikTok integration

Login Kit, profile, analytics, and Content Posting

An authorized TikTok user connects via TikTok’s official authorization screen. Merist then uses only the scopes TikTok and that user approve.

Login Kit · connection workflow

  1. 1
    Operator starts Connect TikTok inside Merist.
  2. 2
    TikTok shows the official authorization screen with requested scopes.
  3. 3
    Account owner approves or denies. Merist never collects the TikTok password.
  4. 4
    Granted capabilities apply only to that connected account.
  5. 5
    Owner can revoke in TikTok settings; operator can disconnect in Merist.

TikTok Content Posting

Draft Upload · Direct Post · confirmation · status

Separate from analytics Connect. Uses Content Posting API scopes video.upload and video.publish. Autonomous unrestricted publishing stays disabled.

Arming map · observe before submit

  1. 1
    Sandbox / app credentials configured in the operator environment
  2. 2
    Publish scopes video.upload / video.publish granted
  3. 3
    Connection publish-authorized (upgrade path when needed)
  4. 4
    Draft Upload / Direct Post status reads ready
  5. 5
    Operator checkbox confirmation on this panel
  6. 6
    Autonomous publish remains disabled

Ready ≠ public Production Content Posting approval. This site does not claim the Production Content Posting revision is approved until TikTok actually approves it. Unaudited Direct Post remains subject to TikTok restrictions (SELF_ONLY / private).

Security

Tokens, revocation, and action boundaries

  • Authorization happens on the platform’s own pages (TikTok Login Kit / OAuth).
  • Merist does not collect platform passwords.
  • Access / refresh tokens are handled on Merist servers — not exposed on this public site.
  • Actions stay within granted scopes on the connected account only.
  • Users can disconnect in Merist or revoke the app in TikTok account settings.
  • Unrestricted autonomous TikTok publishing remains disabled.
