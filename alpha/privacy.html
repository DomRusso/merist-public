Privacy Policy

Last updated: 16 August 2026

Alpha AORE is an operator market-intelligence system. It is not Merist and it does not run a public consumer login.

Data we collect

  • Source identifiers the operator registers, such as a public X handle and, after verification, that account’s X user ID.
  • Public post text, timestamps, and links returned by official APIs when the operator has authorized paid access.
  • API credentials the operator installs on their own server. Those secrets are not shown on these pages.

Data we do not collect

  • X user email addresses.
  • Platform passwords.
  • Payment card numbers.
  • Private community content the operator is not allowed to read.

How we obtain data

Data comes from legitimate public pages and official APIs. Alpha AORE does not scrape behind logins, bypass retailer protections, or use unofficial X access.

Use

Data is used to inform restock, release, preorder, and collectible market decisions for the operator. It is not sold. Alpha does not post as this identity.
